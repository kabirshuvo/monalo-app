# Digraphs image prompts

Style to match Vowel Words: **400×400 kid-friendly flat illustration**, soft pastel background, single clear subject, **no text**, centered, early-literacy app asset.

Drop finished files as `.webp` under `public/digraphs/images/...`, then run:

```bash
node scripts/sync-digraphs-image-paths.mjs --write
```

## Digraph hub cards (`images/digraphs/`)

| File | Prompt |
|------|--------|
| `sh.webp` | Playful card showing a small red ship on blue water, amber sky, bold SH letter shapes integrated subtly, kid app icon style, no words |
| `ch.webp` | Friendly potato chip or chicken chick, warm orange tones, subtle CH letter motif, kid literacy card, no text |
| `th.webp` | Thin thumb pointing up or thin stick figure, soft teal background, subtle TH motif, kid app card, no text |
| `wh.webp` | Cute whale spouting water, sky blue palette, subtle WH motif, kid literacy card, no text |
